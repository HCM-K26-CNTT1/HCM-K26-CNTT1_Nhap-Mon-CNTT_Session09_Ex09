# CLB Lập trình PTIT

## 1. Giới thiệu CLB

**CLB Lập trình PTIT (PTIT Programming Club)** là nơi kết nối những sinh viên yêu thích công nghệ thông tin, cùng nhau học tập, thực hành lập trình và phát triển các dự án thực tế.

Điểm nổi bật của CLB là **học đi đôi với thực hành**, khuyến khích tinh thần tự học, làm việc nhóm và chia sẻ kiến thức giữa các thành viên.

### Mục tiêu hoạt động

-   Xây dựng nền tảng lập trình vững chắc cho thành viên.
    
-   Tổ chức các buổi chia sẻ kiến thức và luyện tập thuật toán.
    
-   Phát triển dự án phần mềm theo nhóm.
    
-   Tạo môi trường học tập thân thiện, sáng tạo và chuyên nghiệp.

## 3. Hướng dẫn gia nhập CLB

Thành viên mới thực hiện lần lượt các bước sau:

1.  **Bước 1:** Đăng ký tham gia CLB thông qua biểu mẫu do Ban Kỹ thuật cung cấp.
    
2.  **Bước 2:** Cài đặt Git trên máy tính và tạo tài khoản GitHub.
    
3.  **Bước 3:** Mở Git Bash hoặc Terminal, sau đó sao chép repository tài liệu của CLB về máy.
    
    ```
    git clone https://github.com/ptit-programming-club/club-wiki.git
    ```
    
4.  **Bước 4:** Di chuyển vào thư mục dự án và kiểm tra trạng thái Git.
    
    ```
    cd club-wiki
    git status
    ```
    
5.  **Bước 5:** Đọc tài liệu hướng dẫn, hoàn thành checklist thành viên mới và liên hệ Ban Kỹ thuật nếu cần hỗ trợ.
    

**Lưu ý:** Đường dẫn repository trong ví dụ cần được thay bằng URL chính thức nếu CLB sử dụng repository khác.

## 4. Checklist nhiệm vụ thành viên mới

Thành viên mới cần kiểm tra và hoàn thành các nhiệm vụ sau:

-   Đọc nội quy và tìm hiểu mục tiêu hoạt động của CLB.
    
-   Tạo tài khoản GitHub.
    
-   Cài đặt Git và kiểm tra bằng lệnh `git --version`.
    
-   Tham gia nhóm trao đổi chính thức của CLB.
    
-   Hoàn thành hướng dẫn Git cơ bản.
    
-   Đọc tài liệu chuyên môn do Ban Kỹ thuật cung cấp.
    
-   Tham gia buổi sinh hoạt đầu tiên của CLB.
    

## 5. Lưu ý quan trọng

> **Deadline:** Thành viên mới cần hoàn thành checklist trong vòng **7 ngày kể từ ngày gia nhập CLB**. Nếu gặp khó khăn, hãy chủ động thông báo cho trưởng Ban phụ trách.
> 
> **Quy tắc ứng xử:**
> 
> -   Tôn trọng các thành viên, lắng nghe ý kiến khác biệt và giao tiếp lịch sự.
>     
> -   Không sao chép mã nguồn hoặc tài liệu của người khác mà không ghi nhận nguồn.
>     
> -   Không chia sẻ mật khẩu, token truy cập hoặc thông tin nội bộ của CLB ra bên ngoài.
>     
> -   Khi đặt câu hỏi kỹ thuật, hãy trình bày rõ vấn đề, các bước đã thử và thông báo lỗi gặp phải.
>     
> -   Chủ động cập nhật tiến độ và chịu trách nhiệm với nhiệm vụ được giao.
>
